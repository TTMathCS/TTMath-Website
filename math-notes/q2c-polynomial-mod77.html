Problem 2(c) · the hard one

Splitting + Fermat + CRT, all together · budget ~10 min in class

Boss level. Splitting, Fermat, and CRT all show up at once. Take it slow — every tool you've met earns its keep here.
Solve.  2x¹²¹ + 22x³⁶ + 21x³⁰ + 2 ≡ 0 (mod 77).
Try it first — show / hide the full solution Tool chain: split 77 = 7 × 11 → reduce each line with Fermat → CRT

New to Fermat's Little Theorem? → full explanation here (what it is, why it's true, and an interactive demo).

Split mod 77 into mod 7 and mod 11

2x¹²¹ + 22x³⁶ + 21x³⁰ + 2 ≡ 0   (mod 7)
2x¹²¹ + 22x³⁶ + 21x³⁰ + 2 ≡ 0   (mod 11)

Simplify the coefficients

Mod 7: 22 ≡ 1, 21 ≡ 0.   Mod 11: 22 ≡ 0, 21 ≡ −1.

2x¹²¹ + x³⁶ + 2 ≡ 0   (mod 7)
2x¹²¹ − x³⁰ + 2 ≡ 0   (mod 11)

Solve mod 7 with Fermat

If 7 | x, every x-term is 0 and we'd get 2 ≡ 0 (mod 7) — false. So 7 ∤ x and x⁶ ≡ 1 (mod 7). Reduce exponents mod 6:

121 = 6·20 + 1  →  x¹²¹ = (x⁶)²⁰·x ≡ x
36  = 6·6       →  x³⁶  = (x⁶)⁶   ≡ 1

2x + 1 + 2 ≡ 0  (mod 7)
2x ≡ 4          (mod 7)
x ≡ 2           (mod 7)
Why each line? (the substitution and the "divide by 2")

Where the equation starts. After splitting mod 77 and reducing coefficients mod 7 (22 ≡ 1, 21 ≡ 0), the mod-7 equation is 2x¹²¹ + x³⁶ + 2 ≡ 0 (mod 7).

Why the powers shrink. Two plain algebra rules, then Fermat:

  • adding exponents: xᵃ⁺ᵇ = xᵃ · xᵇ
  • power of a power: (xᵃ)ᵇ = xᵃᵇ

For x¹²¹, divide 121 by 6: 121 = 6·20 + 1, so

x¹²¹ = x¹²⁰⁺¹ = (x⁶)²⁰ · x ≡ 1²⁰ · x = x   (mod 7)

For x³⁶, divide 36 by 6: 36 = 6·6 + 0 (no remainder), so

x³⁶ = x⁶ˣ⁶ = (x⁶)⁶ ≡ 1⁶ = 1   (mod 7)

Picture x⁶ ≡ 1 as a "reset to 1." The quotient counts the full resets (each becomes 1); the remainder is the leftover exponent that survives. So only the exponent mod 6 matters: 121 mod 6 = 1 → x;  36 mod 6 = 0 → 1.

The 2x + 1 + 2 line is just plugging in the reduced powers:

termbecomeswhy
2x¹²¹2·xx¹²¹ ≡ x; the coefficient 2 stays
x³⁶1x³⁶ ≡ 1
22constant, unchanged

So 2x + 1 + 2 = 2x + 3 ≡ 0 (mod 7).

Why 2x ≡ 4. Move the constant across: 2x ≡ −3 (mod 7). On a 7-clock, −3 is the same spot as −3 + 7 = 4, so 2x ≡ 4 (mod 7).

Why x ≡ 2 (dividing by 2). Dividing by 2 is allowed because gcd(2, 7) = 1, so 2 has an inverse mod 7 — namely 4, since 2·4 = 8 ≡ 1 (how to find an inverse). Multiply both sides by 4:

4·2x ≡ 4·4   →   8x ≡ 16   →   x ≡ 2 (mod 7)     [8 ≡ 1, 16 ≡ 2]

Faster: 2·2 = 4, so x = 2 works — and it's the only answer mod 7 because 2 is invertible (nothing else doubles to 4 on a 7-clock).

Solve mod 11 with Fermat

Same way, 11 ∤ x, so x¹⁰ ≡ 1 (mod 11). Reduce exponents mod 10:

121 = 10·12 + 1  →  x¹²¹ ≡ x
30  = 10·3       →  x³⁰  = (x¹⁰)³ ≡ 1

2x − 1 + 2 ≡ 0  (mod 11)
2x ≡ 10         (mod 11)
x ≡ 5           (mod 11)

Glue with CRT

Find x with x ≡ 2 (mod 7) and x ≡ 5 (mod 11). From x ≡ 5 (mod 11) test 5, 16, 27, …: 16 mod 7 = 2 ✓.

x ≡ 16 (mod 77)  — that is, x = 16 + 77k.

Check: 16 mod 7 = 2 ✓ · 16 mod 11 = 5 ✓

Where students get stuck. (1) Forgetting to rule out p | x before using Fermat. (2) Reducing the exponent mod p instead of mod (p−1). Write "exponents live mod (p−1)" on the board and leave it up.
