The modular inverse, via the Euclidean algorithm

The tool behind CRT's yᵢ and behind RSA's private exponent

Goal. Given a and m, find the inverse of a mod m — the number b with a · b ≡ 1 (mod m).

1. What it is, and when it exists

On an m-hour clock, the inverse of a is the number you multiply a by to land back on 1. For example mod 7, the inverse of 3 is 5, because 3 · 5 = 15 ≡ 1 (mod 7).

It exists exactly when gcd(a, m) = 1 (a and m are coprime). If they share a factor, no multiple of a ever lands on 1, so there is no inverse.

2. The idea: Bézout's identity

The extended Euclidean algorithm finds whole numbers x, y with

a · x + m · y = gcd(a, m)

When gcd(a, m) = 1, read that equation mod m: the m · y term vanishes, leaving a · x ≡ 1 (mod m). So x is the inverse (reduced into the range 0…m−1).

3. Worked example: inverse of 3 mod 40

(This is the exact step RSA needs to turn the public exponent e = 3 into the private d.)

Run Euclid's algorithm (divide, keep remainders)

40 = 13 × 3 + 1
 3 =  3 × 1 + 0

The last nonzero remainder is 1, so gcd(3, 40) = 1 — an inverse exists.

Back-substitute to isolate the 1

Take the line that produced the remainder 1 and solve for it:

1 = 40 − 13 × 3

So −13 × 3 = 1 − 40 ≡ 1 (mod 40).

Reduce the coefficient into 0…39

inverse of 3 = −13 ≡ −13 + 40 = 27 (mod 40)
3⁻¹ ≡ 27 (mod 40)

Check: 3 × 27 = 81 = 2 × 40 + 1 ≡ 1 (mod 40). ✓

5. The same thing in Python

  
The whole method is a short loop. This returns the inverse, or None when there
  isn't one (gcd ≠ 1).

  
# inverse of a modulo m, by the extended Euclidean algorithm
def inverse(a, m):
    old_r, r = a % m, m
    old_s, s = 1, 0
    while r:
        q = old_r // r
        old_r, r = r, old_r - q * r
        old_s, s = s, old_s - q * s
    if old_r != 1:              # gcd(a, m) != 1, no inverse
        return None
    return old_s % m

print(inverse(5, 43))          # 26   (5 * 26 = 130 = 3*43 + 1)

  
The pair old_s, s carries Bézout's coefficient for
  a as the loop runs, so at the end old_s · a ≡ 1 (mod m)
  — that is the inverse. The other coefficient (for m) isn't needed, so we don't track it.


  
Even shorter (Python 3.8+): the built-in pow does it directly —

  
print(pow(5, -1, 43))          # 26
