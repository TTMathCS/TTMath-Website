Why CRT is true — the proof

Two parts: there is at most one answer (uniqueness), and there is at least one (existence)

Theorem. Let n₁, …, nₖ be pairwise coprime — gcd(nᵢ, nⱼ) = 1 for every i ≠ j. For any a₁, …, aₖ, the system x ≡ aᵢ (mod nᵢ) (for all i) has a solution, and any two solutions differ by a multiple of
N = n1·n2·⋯·nk = k∏i=1 ni
In short: exactly one solution mod N.

Part A — Uniqueness (at most one answer mod N)

Suppose two numbers both work

Let x and x′ each satisfy all the congruences. For every i,

x ≡ aᵢ (mod nᵢ)  and  x′ ≡ aᵢ (mod nᵢ)   →   x − x′ ≡ 0 (mod nᵢ)

So each nᵢ divides the difference x − x′.

Coprime divisors multiply

A number divisible by several pairwise coprime numbers is divisible by their product. (If n₁ and n₂ share no factor and both divide D, then n₁n₂ divides D; repeat.) Hence

ni | (x − x′) for every i  ⟹  k∏i=1 ni = N  |  (x − x′)

That is x ≡ x′ (mod N) — any two solutions are the same modulo N. So there is at most one answer in 0 … N−1.

Where coprime is used: Step 2. Without it, the separate divisibilities would only give the lcm, not the product — and the clean "one answer mod N" breaks (exactly what you see in the failing grid on the CRT page).

Part B — Existence (at least one answer), by construction

We don't just argue an answer exists — we build it. This is the same formula used on the CRT page and in RSA.

Build a "selector" for each clock

Let Mᵢ = N / nᵢ — the product of all the other moduli. Because the moduli are pairwise coprime, Mᵢ shares no factor with nᵢ, so gcd(Mᵢ, nᵢ) = 1 and Mᵢ has an inverse yᵢ mod nᵢ (found by the Euclidean algorithm).

Notice the key property of Mᵢ: it is a multiple of every other modulus, so

Mᵢ ≡ 0 (mod nⱼ) for j ≠ i,   and   Mᵢ · yᵢ ≡ 1 (mod nᵢ)

Add the selectors, weighted by the targets

x = a1M1y1 + a2M2y2 + ⋯ + akMkyk = k∑i=1 aiMiyi

Check it lands correctly on every clock

Look at x modulo a fixed nᵢ. Every term with j ≠ i contains Mⱼ, which is ≡ 0 (mod nᵢ) — so those terms vanish. Only the i-th term survives:

x ≡ aᵢ · Mᵢ · yᵢ ≡ aᵢ · 1 = aᵢ (mod nᵢ)

This holds for every i, so x satisfies the whole system. An answer exists. ∎

A shorter existence argument (counting)

Part A shows the map sending a number to its list of remainders,

x  ⟼  ( x mod n1,  … ,  x mod nk )

never sends two different values of {0, …, N−1} to the same list — it is injective. But both sides have exactly N = k∏i=1 nᵢ elements, and an injective map between finite sets of equal size is automatically onto. So every possible list of remainders is hit — existence, for free. (This is the grid filling every cell exactly once.)

Two moduli, by hand. For just n₁, n₂: write x = a₁ + n₁t from the first congruence, plug into the second to get n₁t ≡ a₂ − a₁ (mod n₂); since gcd(n₁,n₂)=1, n₁ is invertible mod n₂, so t is determined mod n₂ and x is determined mod n₁n₂. Chaining this two at a time proves the general case by induction.
